### Introduction
#### Definitions and Trends
- **Defnition**:
	- IoT is a network where **physical devices** ,and products which **embeded with electronic devices, softwares and sensors**.
	- These things are granted abilities to **feel, compute and connect** the world.

#### Application structure and Challenge
-  A normal structure is like this
![image.png](https://tu.shanchui.cc/file/blog/wenzhang/1789537891633_image.png)
- **Challenges**:
	- The Dev Tech chain is too long to handle.
		- Low code and AI-assist coding is a great chance
	- IoT don't have fixed type of teminal device
		- No big companys have succeeded in ruling this place. IoT is speeding to develop in a direction of low energy cost and small volume
	- IoT Dev chain has several fixed types
		- The Blockchain *Matter* Protocol provides "decentalized" authentication
		- Opensource cloud software platform is making "standalized" future possible
